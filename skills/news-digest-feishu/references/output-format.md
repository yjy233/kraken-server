# Output Format

The final digest should use this structure:

```markdown
# 今日新闻摘要

## 总览
- 3 到 5 条主题级总结

## 详细条目
1. 标题
   来源：36氪
   时间：2026-05-07 07:40
   摘要：...
   影响：...
   链接：...
```

Rules:

- No more than 20 detailed items.
- Every item must include source and link.
- Prefer concise summaries suitable for morning reading.
- Merge duplicate stories into a single item when multiple portals cover the same event.
